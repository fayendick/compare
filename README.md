# Compare — Finance & Balance Comparison Tool

A lightweight Streamlit application for comparing Finance Report and Balance Détaillé files.

## Features

- Upload Finance Report and Balance Détaillé Excel files
- Compare opening balances
- Compare closing balances
- Calculate total opening balance
- Calculate total closing balance
- Identify accounts with different opening balances
- Identify accounts with different closing balances
- Identify accounts with the largest mismatches
- Display comparison results through a Streamlit interface

## Technologies

- Python
- Streamlit
- Pandas
- OpenPyXL
